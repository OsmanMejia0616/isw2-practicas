# Práctica 1: Clean Code, Code Smells y Refactorización

## Objetivo

Analizar código fuente para identificar problemas de legibilidad y mantenimiento, documentar los code smells encontrados y realizar una refactorización segura.

## Contenido

* `diagnostico-smells.md`: diagnóstico de los problemas identificados en el código.
* `refactor/`: documentación y código relacionado con la refactorización.
* `evidencias/`: evidencias del trabajo realizado.

## Diagnóstico

Se documentarán los problemas encontrados en el código analizado, su ubicación, sus consecuencias y las posibles mejoras.

## Refactorización

Se describirán los cambios realizados y las comprobaciones utilizadas para verificar que se conserva el comportamiento esperado.

## Verificación

Se registrarán las pruebas ejecutadas y sus resultados.
